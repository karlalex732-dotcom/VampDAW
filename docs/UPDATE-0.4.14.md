# VampDAW Alpha 0.4.14

Волна аудио в Playlist теперь использует всю высоту клипа и центрируется по вертикали. При растягивании дорожки она сразу меняет высоту. При приближении по времени показываются более подробные пики; учитываются оба стереоканала, смещение клипа и карта темпа. Короткие атаки сохраняются и в общем виде.

Высота волны нормируется по пику исходного аудиофайла только для отображения: это помогает видеть тихие записи. Громкость, содержимое файла и экспорт этим не меняются. Название клипа рисуется поверх волны. Текущий дубль при записи также использует полную доступную высоту, с исходной шкалой уровня входа.

Данные для волн готовятся в фоне и повторно используются на всех уровнях масштаба. Память кэша ограничена; данные закрытых проектов освобождаются. Первое короткое приближение волны уточняется после фонового анализа.

В Sequencer → Drum generator добавлено поле **Subgenre / Поджанр**. У каждого из 20 жанров есть пять поджанров, всего 100, и прежний базовый грув. Поджанр задаёт расположение бочки, снейра, хэтов, перкуссии, райда и характер дробей. Плотность, Swing, Humanize, Variation и Fills остаются доступными. Паттерны строятся из назначенных пользовательских сэмплов; результат можно редактировать как обычный MIDI.

**Reroll / Новый вариант** сохраняет жанр, поджанр и остальные выбранные параметры. У каждого жанра запоминается последний поджанр; выбранный жанр и этот список сохраняются между запусками. Название нового паттерна содержит поджанр.

Примеры: Dubstep — Brostep, Tearout, Deathstep, Melodic, Deep; Drum & Bass — Liquid, Neurofunk, Jump-up, Jungle, Drumstep; House — Deep, Tech, Progressive, Bass, French; Metal — Thrash, Death, Black, Metalcore, Djent. Названия и элементы управления доступны на русском и английском.

Установщик: `dist/VampDAW-0.4.14-alpha-win64-Setup.exe`. Windows 11 x64, Intel/AMD; разработчик Karsei, GPLv3 и соответствующие исходники в комплекте.
