# ARA в VampDAW

В 0.4.18 добавлен ARA 2 для Windows VST3. Интеграция пока экспериментальная: протокол, чтение аудио, воспроизведение, архивы правок, экспорт и интерфейс проверены тестовым плагином. Melodyne и Vovious на этом компьютере отсутствуют; совместимость их конкретных версий пока не подтверждена.

## Как открыть

1. Помести аудиоклип на отдельную дорожку плейлиста. На ней должны быть аудиоклипы; семплер, VST-инструмент и живой аудиовход для этой дорожки должны быть отключены.
2. Нажми ПКМ по клипу → **Edit with ARA / Melodyne / Vovious…** (в русском интерфейсе — «Редактировать через ARA…»).
3. Выбери установленный ARA-редактор из вкладки **User** или **Starred**. При пустом списке нажми **Rescan**, либо **Choose VST…** и укажи ARA-версию файла `.vst3`.
4. Редактор получает аудио напрямую, без записи в реальном времени и команды Transfer. Перемещение, обрезка и удаление клипов передаются в ARA. Копия клипа получает собственный идентификатор и копию правок.

Подключённый плагин отмечен **[ARA]**. Он занимает первый из 16 слотов дорожки; остальные эффекты располагаются после него. Нажатие на источник в инспекторе или микшере снова открывает редактор. Bypass возвращает исходное аудио.

## Сохранение и рендер

Сохраняй проект `.vamp`: он содержит архив анализа и правок ARA. Исходные аудиофайлы по-прежнему нужны. Идентификаторы клипов сохраняются вместе с архивом. Проекты с ARA используют версию формата 9 и требуют VampDAW 0.4.18 или новее; обычные проекты продолжают сохраняться в формате 8.

Для вывода используй экспорт песни, диапазона или выделенных клипов. **Bounce in place** передаёт ARA только выбранные клипы и возвращает полный документ после обработки. Freeze использует тот же звуковой тракт. Экспорт MIDI не переносит ARA-правки.

ARA применяется к отдельной аудиодорожке, а не к Master или принимающей шине. Направлять её выход на обычную шину можно; направлять другие аудиодорожки на ARA-источник нельзя. Это предотвращает потерю поступающего на него звука. VST2 и ARA 1 не поддерживают этот режим.

Если редактор или совместимая версия плагина отсутствует, сохрани исходный проект и его аудио. Сообщение о несовместимом ARA-архиве означает, что правки не были восстановлены; не заменяй единственную копию проекта до проверки.

## Основа и проверки

Используется официальный [ARA API 2.3.0](https://github.com/Celemony/ARA_API/tree/releases/2.3.0), commit `65ec5c43b943a48cb5446f448a0492db6af8534b`, Apache 2.0. Заголовки и лицензия включены в комплект исходников. Проверки запускаются через `build.ps1 -Tests`, проверка интерфейса — `VampDAW.exe --ara-ui-check <report.json>` после сборки тестового плагина.
