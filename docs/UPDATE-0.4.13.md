# VampDAW Alpha 0.4.13 — исправление аудио в старых проектах

Исправлена причина ошибки «Не удалось открыть WAV» в проекте «Ленивец.vamp» версии 7.

При сохранении проекта на одном диске и сэмплов на другом `relative()` возвращал пустой путь без ошибки. Программа записывала этот пустой путь в проект; при открытии он превращался в папку проекта, которую загрузчик пытался прочитать как WAV. Теперь для разных дисков записывается абсолютный путь. Это относится к инструментальным сэмплам, аудиоклипам, кэшам Freeze и общему сигналу анализа Warp. Для файлов на одном диске сохраняются относительные пути.

Старый проект с отсутствующим файлом или пустой ссылкой теперь открывается с уведомлением. Ноты, паттерны, клипы, плагины и параметры сохраняются; недоступное аудио остаётся беззвучным и не заменяется синтезатором. **SESSION → Locate project audio… / Найти аудио проекта…** показывает список проблемных ссылок. Выберите элемент и укажите исходный аудиофайл, затем сохраните проект. Все ссылки на один и тот же файл заменяются вместе; действие можно отменить. Для пустых ссылок старой версии исходное расположение восстановить из самого проекта невозможно.

Сэмплы, которые находятся только в памяти, при первом сохранении записываются в `assets` рядом с проектом в WAV float32, без квантования и обрезания амплитуды. Повторные сохранения используют уже созданный файл. Поддержана загрузка сохранённых ссылок на сжатое аудио через штатный декодировщик Windows. При выборе более короткого файла позиции слайсов ограничиваются его действительной длиной.

Для «Ленивец.vamp» найдены шесть исходных ударных с точными названиями в `E:\Drum Kits`. Вместе с доступным басом они скопированы в `E:\VampDAW\projects\Recovered\Ленивец\assets`. Восстановленный проект — `Ленивец-восстановлен.vamp` в этой же папке. Оригинал в Downloads не изменялся. Для переноса копируйте всю папку проекта вместе с `assets`; сторонние VST устанавливаются отдельно.

Формат проекта остаётся v8 с чтением v1–v8. Функции Night Desk описаны в [UPDATE-0.4.12.md](UPDATE-0.4.12.md). Установщик — `dist/VampDAW-0.4.13-alpha-win64-Setup.exe`, GPLv3, разработчик Karsei, исходники включены.
