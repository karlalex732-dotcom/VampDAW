# VampDAW 0.4.19 Alpha

Пиано ролл и секвенсор получили независимые размеры внутри рабочего окна.

- **Piano roll:** потяни нижнюю границу с тремя точками, чтобы изменить высоту. При увеличении появляется больше нот с сохранением плотности строк. Меню **oct ▾ / окт ▾** позволяет сразу показать 2, 3, 4 или 5 полных октав. При необходимости оно увеличивает панель и уменьшает область velocity, чтобы выбранные октавы поместились. Прокрутка нот, выделение и редактирование используют новую высоту строк.
- **Sequencer:** потяни правую границу с тремя точками, чтобы изменить ширину. В меню **Bars: / Такты:** доступны 1, 2, 4, 8 и 16 тактов, то есть до 256 шагов на строку. Номера тактов и разделители помогают ориентироваться в длинном паттерне. Нажатие на поздний шаг увеличивает реальную длину паттерна до соответствующего такта. Выбор видимого диапазона сам по себе музыку не меняет.
- Двойной щелчок по границе восстанавливает автоматический размер панели. **Expand / Enter** по-прежнему разворачивает редактор на доступную область рабочего окна. Ctrl + колесо и кнопки − / % / + сохраняют управление масштабом секвенсора.
- Высота, ширина, плотность нот и выбранное количество тактов сохраняются при следующем запуске. Размеры ограничиваются доступным местом; элементы не выходят за рамки приложения. Масштаб всей программы не меняется.

В длинном секвенсоре ноты индексируются один раз на строку вместо повторного просмотра всего паттерна для каждого из 256 шагов. Звуковой движок и формат проектов не изменены. Включены функции ARA и предыдущих выпусков.

Проверки: русский и английский интерфейс, компактная и широкая компоновка, 3/4/5 октав и соответствие координат MIDI-нотам, перетаскивание обеих границ через обработчики мыши, 256 доступных шагов, запись в последний шаг 16-го такта, границы прокрутки, сохранение настроек и отсутствие изменений музыки при настройке вида.
