# VampDAW 0.4.15 Alpha

Разработчик: Karsei. Windows 11 x64, Intel / AMD. Лицензия GPL-3.0-only.

## Playlist: управление клипами

- Перемещение аудио и паттернов — ЛКМ по верхней плашке с названием. Shift создаёт копию; выделенную группу можно перемещать вместе.
- ЛКМ по телу клипа выделяет его. Двойной щелчок открывает Piano roll или Sample Lab. Ctrl сохраняет выделение рамкой.
- Левый край аудио подрезает начало, правый — конец. Обратное перетаскивание возвращает скрытый участок, пока в исходнике остаётся аудио. Конец клипа при подрезке начала остаётся на месте.
- Маленькие угловые ручки задают fade-in и fade-out. Ручки появляются у выделенного клипа и при наведении. Двойной щелчок по ручке убирает соответствующий фейд.
- Кнопка **↔ Stretch** переключает правый край аудио в растяжение с сохранением высоты тона. При выключенной кнопке он снова подрезает конец. Растяжение считается в фоне; исходный файл не меняется. Учитываются карта темпа и существующие Warp-маркеры. Допустимый коэффициент каждого участка — 0,25–4; длинные клипы ограничены десятью минутами.
- Alt временно отключает привязку при подрезке и растяжении. Фейды меняются плавно. Esc отменяет незавершённое перетаскивание. Ctrl+Z отменяет применённое редактирование.
- Сигнал waveform остаётся на высоту клипа и меняется при изменении высоты дорожки и приближении.

## Загрузка в нижней панели

Всплывающее окно статуса удалено. Название операции, подробности, процент и шкала находятся в центре нижней плашки, между аудиоустройством и DSP. Для неизвестной длительности используется движущийся индикатор; при отключённых анимациях он статичен. Несколько параллельных операций по очереди показываются с номером `1/N`. Завершение убирает индикатор и возвращает обычное сообщение.

## Oracle Assist внутри VampDAW

В заголовке выбирается **Vamp only / All plugins**. Все 30 сценариев, локальный анализ и длительность 1–30 секунд сохранены. В режиме All Oracle использует просканированный каталог VST2/VST3; можно заменить эффект любого этапа через **Choose…**. Автоматический выбор сопоставляет назначение эффекта с результатами анализа звука. При отсутствии подходящего пользовательского эффекта остаётся настроенный Vamp.

Oracle читает названия, единицы и числовые показания регуляторов. Для VST2 и VST3 он проверяет монотонность показаний и вычисляет нормированное значение по действительному диапазону, включая логарифмические частоты, времена и ratio. Семантическое сопоставление охватывает совместимые пороги, ratio, атаку/восстановление, gain/makeup, частоты/усиление/Q распознанных полос EQ, срезы фильтров и другие однозначные параметры.

После анализа выполняется пробный прогон подходящего фрагмента захваченного сигнала длиной до двух секунд через **новые, ещё не подключённые экземпляры эффектов**. Следующий порог динамической обработки учитывает измеренное изменение уровня после предыдущих этапов. Финальный gain/вход лимитера учитывает текущий уровень. Состояние обработки после прогона сбрасывается перед подключением. Пресет без анализа остаётся предпросмотром без измерительной калибровки.

В каждой строке показано число распознанных регуляторов и измеренные уровни до/после. ПКМ → **Show suggested settings** показывает отчёт: выбранный параметр, единицы, фактическое показание либо отметку «не распознан — оставлен без изменений». Oracle не угадывает непрозрачные настройки, не обходит защиту плагинов и не обещает понимать любой закрытый DSP. Проверяйте такие параметры через **Open** и на слух. Произвольные названия, текстовые переключатели, нестандартные единицы и некоторые сложные внутренние модули могут потребовать ручной настройки.

Применение вставляет реальные эффекты **сразу после Oracle**, сохраняет последующие эффекты и переносит их автоматизацию вместе со слотами. Лимит — 16 слотов на канал, включая Oracle. Ctrl+Z отменяет вставку. Результат пробного прогона относится к создаваемой цепочке; последующие существующие эффекты канала и Master могут менять звук дальше.

## Oracle Rack для других DAW

Отдельный **Oracle Rack 0.1.0 Alpha** — VST3-эффект для Windows x64. VampDAW для его работы не нужна. По умолчанию включён All plugins. Внешние VST2/VST3 загружаются и обрабатываются внутри Oracle; настроенные Vamp-эффекты доступны как встроенная основа и резерв. Синтезаторы и сам Oracle исключены из автоматического выбора эффектов.

Установщик: `dist/Oracle-Rack-0.1.0-alpha-win64-Setup.exe`. Переносной комплект: `dist/Oracle-Rack-0.1.0-win64.zip`. Подробности — [ORACLE-RACK.md](ORACLE-RACK.md).

## Проверка и ограничения альфы

Проверяются фактические обработчики мыши, сохранение исходного конца при подрезке, фейды, фоновые Warp-операции, карта темпа и сохранение высоты тона. Oracle проверяется на физических регуляторах тестового VST2, реальной обработке вложенных эффектов, сохранении/восстановлении, суммировании задержки, bypass с компенсацией задержки и через независимый VST3-host: моно/стерео, 32/64-битные буферы и большие блоки. Протоколы находятся в `work/test-results` и итоговом `docs/verification-0.4.15.json`.

Это не проверка всех сторонних плагинов и DAW. Внутренняя обработка Rack — float32; float64-буферы хоста преобразуются. Поддерживаются плагины Windows x64, не 32-bit bridge, AU или AAX. Изменение задержки вложенного эффекта сообщает хосту о необходимости пересчёта компенсации; поведение перезапуска зависит от хоста. Сканы выполняются отдельным процессом с таймаутом. Сам звук сторонних эффектов обрабатывается в процессе DAW, поэтому сбой такого эффекта может затронуть хост.
