# VampDAW 0.4.18 Alpha

Добавлена экспериментальная интеграция **ARA 2 / VST3** для аудиоклипов плейлиста. В меню клипа по ПКМ появилась команда выбора ARA-редактора; список показывает совместимые плагины и метку ARA. Подключённый редактор занимает первый слот аудиодорожки, получает аудио напрямую, позиции клипов, карту темпа и размеры тактов.

Поддержаны перемещение, обрезка, удаление и дублирование клипов с копированием ARA-правок, сохранение и восстановление архивов правок, управление транспортом из редактора, выбор клипа, вывод через микшер, экспорт, Bounce in place и Freeze. Синхронизация перед сохранением учитывает жесты, ещё ожидающие публикации в звуковой движок. Рендер выделения временно передаёт ARA соответствующий набор клипов и восстанавливает полную модель после рендера.

Включены изменения 0.4.17: все доступные логические процессоры для DSP, лимит интерфейса 60–240 FPS и исправление мерцания нижней панели.

**Проверено:** собственный VST3 ARA-плагин, чтение float32/float64, границы аудио, жизненный цикл общего ARA-factory и документов, копирование правок по persistent ID, восстановление проекта, рендер, транспорт, компоновка на русском и английском. **Не проверено:** установленные Melodyne и Vovious — они находятся на другом ПК. Наличие ARA в сборке не является подтверждением совместимости каждой коммерческой версии. Инструкция: [ARA.md](ARA.md).
