# VampDAW 0.4.10 — клавиши

Секвенсор: Ctrl+колесо или − / + меняют только его масштаб (50–200%);
нажатие процента возвращает 100%. Shift+колесо прокручивает увеличенные шаги.
Blood Stems: × / Esc возвращает в Sample Lab, не отменяя разделение в фоне.

Основные сочетания соответствуют привычной раскладке музыкальных редакторов. Действие зависит от активного окна. Однобуквенные P/B/D/E/C/T/Y/Z, R, L и F работают при выключенной игре с компьютерной клавиатуры. Ctrl+T переключает этот режим; сочетания с Ctrl/Alt и функциональные клавиши остаются доступны.

Все панели можно закрыть кнопкой × и вернуть через Views. Закрытие интерфейса эффекта сохраняет обработку и его параметры. В стороннем VST остаются собственные сочетания самого плагина. Общий масштаб интерфейса задаётся в Settings → Animation; Shift+колесо его не меняет.

В Blood EQ: перетаскивание точки — частота/усиление, колесо — Q, Ctrl — точная регулировка, ПКМ — фильтр/числа, двойной щелчок — 0 dB, Tab — следующая полоса, стрелки — точная правка полосы, Esc — скрыть окно.

Автоматизация открывается в том же рабочем пространстве, что Playlist, Mixer и Piano roll: вкладка Automation или Views → Automation. Alt+O открывает / закрывает её; Esc и × закрывают, Enter и кнопка Expand разворачивают / возвращают компоновку. Tab включает автоматизацию в общий цикл редакторов. Выберите канал и параметр сверху; рисуйте мышью. Линии сохраняются при закрытии и переключении редакторов. Горизонтальный ползунок и стрелки перемещают время, Ctrl+колесо и −/+ меняют масштаб времени. ↑/↓ меняют значение последней точки, Ctrl даёт шаг 0,1%.

Высота Playlist: тяните горизонтальную границу «Playlist height ↕» под плейлистом вверх / вниз. Нижний микшер отдаёт или получает это место; внизу его можно свернуть. Двойной щелчок по границе возвращает исходную высоту микшера.

Ctrl+Shift+G — создать папку из выделенных дорожек. Ctrl+щелчок по заголовкам Playlist/Mixer или дорожкам в браузере → Tracks добавляет/убирает дорожку из группы; Shift выбирает диапазон. ПКМ по папке открывает вложение и перемещение.

Высота отдельной дорожки: тяните нижнюю границу её заголовка вверх/вниз. Двойной щелчок по границе сбрасывает высоту. Это не меняет высоту соседних дорожек.

Mixer: ПКМ / двойной щелчок по фейдеру или панораме — точное число. Колесо меняет уровень, Ctrl+колесо — точнее. Кнопка Selected открывает групповые действия. Кнопки ‹ FX / FX › и колесо над слотами показывают остальные эффекты. Перетаскивание занятого FX-слота в другой слот того же канала меняет эффекты местами. При переносе между страницами задержите курсор на кнопке листания.

Oracle Assist: Analyze sound слушает 1–30 секунд текущего слота; время задаётся ползунком. Выбор сценария отключает Auto profile. ПКМ по этапу — подробности; колесо и полоса прокрутки — список цепочки. Apply chain добавляет эффекты, обычная команда Undo отменяет добавление.


0.4.6: ПКМ по линейке тактов Playlist снимает диапазон. Views → Project Pool открывает вкладки Patterns / Audio: поиск, Space — прослушать, Enter / двойной щелчок — открыть, перенос в Playlist или Add at cursor. Sample Lab → Blood Stems открывает разделение в лаборатории; Editor возвращает к волне. Settings → Customize theme открывает девять цветов с предпросмотром; ПКМ на цвете — HEX, Save сохраняет, Cancel возвращает прежнюю тему. Файлы .vamptheme можно экспортировать и импортировать.

Маркеры Playlist: перетащите флажок для изменения позиции с текущей сеткой (Alt отключает привязку). Двойной клик или F2 меняет имя. ПКМ открывает имя, точную позицию такт:доля, цвет и удаление. Delete удаляет только выбранный маркер; Escape снимает выбор, Ctrl+Z отменяет изменение. При выключенной игре с клавиатуры ←/→ двигают маркер на шаг сетки, Shift+←/→ — на такт.

Blood Composer (Sequencer → Drum generator, Piano roll → Generate): R — новый вариант; Space — прослушать/стоп; Enter — применить; Esc — закрыть без применения. Ctrl+Z после применения отменяет создание всех паттернов целиком. В Melody generator есть режим Bass line.
Папки Playlist: перетаскивание нижней границы — высота папки; двойной щелчок по границе — автоматическая высота.
