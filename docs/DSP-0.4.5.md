# Audio engine / DSP — 0.4.5

Исправлено применение частоты и буфера в WASAPI: раньше использовались частота Windows и фиксированное запрошенное значение периода. Теперь движок запрашивает выбранный формат и допустимый период, а интерфейс показывает фактические значения. При необходимости shared WASAPI использует преобразование частоты Windows. Это не меняет физическую частоту интерфейса, заданную в системном микшере. ASIO показывает реальные значения драйвера, включая изменения в его панели.

Индикатор DSP теперь учитывает длительность блока при фактической частоте; сглаживание привязано ко времени, а не числу вызовов. Для ASIO учитываются преобразование входа/выхода и завершение буфера. Добавлены пиковая нагрузка и обновление показаний при остановленном транспорте. Оптимизированы преобразования ASIO, копирование стереобуфера и индикаторов, пустой транспорт и постоянный Output встроенных эффектов.

Проверки на доступной системе:

| Запрос | Получено | Результат |
|---|---|---|
| WASAPI 48 kHz, 128 / 1024 | 48 kHz, период 480 | Обе конфигурации работают; Windows сохраняет поддерживаемый период |
| WASAPI 96 kHz, 256 | Поток 96 kHz, Windows 48 kHz | Преобразование частоты, звук и статистика работают |
| System Audio ASIO 48 kHz, 128 | 48 kHz, 256 | Показано фактическое ограничение драйвера |
| System Audio ASIO 48 kHz, 1024 | 48 kHz, 1024 | Звук и статистика работают |

Во всех четырёх основных вариантах и варианте с преобразованием частоты короткие smoke-проверки прошли без зарегистрированных XRUN. Это не проверка многочасовой устойчивости. Antelope Zen Quadro на доступном компьютере не подключён; его собственный драйвер отдельно не проверен. Для проверки важно выбрать именно ASIO-драйвер Antelope, если нужен ASIO; надпись Playback 1/2 сама по себе не определяет используемый backend.

Бенчмарк: 32 дорожки, 8 активных, по EQ и компрессору, 44.1/48/96 kHz, блоки 64/128/512/1024, воспроизведение и остановка. Медиана улучшения времени обработки — около 4.2% по всем конфигурациям, около 2.1% при воспроизведении. Контрольная энергия звука совпала во всех 24 вариантах. Это локальное сравнение движка до/после, не сравнение с другой DAW. Больший буфер даёт больше времени на каждый блок, но не обязан заметно уменьшать среднюю стоимость обработки каждого отсчёта.
