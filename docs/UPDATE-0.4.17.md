# VampDAW 0.4.17 Alpha

- Исправление мерцания нижней панели из 0.4.16 включено.
- **Night Desk → Multicore DSP → All cores / automatic** использует число активных логических процессоров Windows во всех процессорных группах. Жёсткий предел в восемь потоков удалён из пула, меню и загрузки настроек. Доступны готовые количества и точный ввод. Один из потоков — вызывающий аудиопоток, остальные — DSP workers. Невостребованные потоки спят. Зависимые шины и сайдчейны по-прежнему выполняются в порядке маршрутизации; один последовательный канал не разделяется между всеми ядрами.
- **Settings → Themes → Frame rate limit / FPS:** 60, 90, 120, 144, 165, 180, 210, 240. Выбор сохраняется и действует при следующем запуске. Сложность анимации выбирается отдельно. Собственный планировщик с таймером высокого разрешения заменяет привязку плавности к старому 16–66-мс таймеру обслуживания. В очереди находится не больше одного сообщения кадра; при отсутствии активности планировщик спит. Ограничение относится к основному интерфейсу VampDAW: сторонние плагины рисуют свои окна самостоятельно. Выбранный предел не гарантирует соответствующий фактический FPS на любом компьютере.

ARA не включена. По просьбе пользователя её разработка отложена; незавершённые экспериментальные файлы убраны из исходников выпуска и сохранены отдельно в рабочей папке разработки.

Проверки включают участие всех доступных DSP-потоков в заданиях, выполнение 51 300 заданий без пропуска и дублирования, переключение single/all, шаги и сохранение FPS/количества DSP-потоков, планирование кадров и сон при простое, визуальную компоновку на двух языках и регрессионные проверки отрисовки нижней панели. Измерения планировщика не являются измерениями FPS отрисованного рабочего стола.
