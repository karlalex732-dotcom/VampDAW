УСТАНОВКА
Запустите VampDAW-0.4.15-alpha-win64-Setup.exe на Windows 11 x64.
Для установки и базовых 4/6 стемов интернет не нужен. Python и библиотеки уже
в комплекте. Дополнительные модели требуют интернет при первом использовании.
PyTorch также использует системный Microsoft Visual C++ Runtime x64.
Если он отсутствует (сообщение о DLL), установите официальный пакет Microsoft:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
Права администратора не требуются. Можно выбрать папку и ярлык на рабочем столе.
Установщик добавляет приложение в меню «Пуск» и список установленных программ.
При повторной установке в ту же папку программа обновляется.
Перед обновлением закройте VampDAW, сохранив открытый проект.

Это неподписанная альфа-сборка: Windows может показать предупреждение об
неизвестном издателе. Проверяйте, что файл получен от организатора тестирования.
SHA-256 файла указан в передаваемом рядом файле SHA256SUMS.txt.

ПЕРВЫЙ ЗАПУСК
1. Откройте VampDAW из меню «Пуск» или с рабочего стола.
2. В SETTINGS / USB MIDI выберите аудиоустройство и MIDI-вход.
   WASAPI работает с системными устройствами. Для ASIO установите x64-драйвер
   производителя интерфейса отдельно; универсальные ASIO-драйверы не входят в пакет.
3. Добавьте папку со звуками в браузере User Sounds.
4. User Plugins > Instruments / FX: добавьте папку своих x64 VST2/VST3 и нажмите ↻ для сканирования каталога.
   Общая системная папка Common Files\VST3 проверяется автоматически.
5. В первом инструментальном слоте выберите семпл или VST3-инструмент.
   Ноты редактируются в Piano roll и секвенсоре. Space — воспроизведение.
6. Сохраните проект через SESSION > Save. Экспорт — SESSION > Export audio.

ОГРАНИЧЕНИЯ АЛЬФЫ
Сохраните резервные копии важных работ до тестирования.
Поддерживаются VST2/VST3 x64; плагины и их лицензии устанавливаются отдельно.
Моста для 32-битных плагинов и поддержки VST2 shell-контейнеров пока нет.
Собственные эффекты — альфа-реализации; пока доступны только внутри VampDAW.
Совместимость со всеми плагинами и физическими USB/ASIO-устройствами не проверена.
Объединение устройств относится к WASAPI внутри VampDAW, не создает системный драйвер.
Преимущество в CPU над другими DAW пока не подтверждено сравнительными замерами.

  в тех же позициях, сохраняя фейдер, панораму, их автоматизацию и маршрутизацию.
  Ctrl+Z возвращает исходники; оригинальные паттерны остаются в Project Pool.
— Ctrl + перетаскивание: рамка выделения плейлиста с автопрокруткой.
  Ctrl + клик: добавить/убрать клип из выделения. Delete: убрать выбранные клипы.
  ПКМ на линейке очищает выбранный диапазон.
— Адаптивная линейка: при отдалении шаг несколько тактов; при приближении
  такты, доли и тики (96 на долю). BAR / BEAT / TICK имеют фиксированные ячейки.
— ПКМ по папке: Freeze / Unfreeze со всеми подпапками. Одна общая отмена Undo,
  последовательная обработка источников и шин, общая шкала и отмена очереди.
— Уже замороженные дорожки пропускаются; внешний MIDI нужно записать в аудио.
— Более узкий микшер и Master; число видимых каналов зависит от ширины окна.
— Project Pool: поиск, сортировка, несколько выбранных элементов, счётчик
  размещений, фильтр, укладка последовательно или слоями, поиск в плейлисте.
— Общий индикатор загрузки в углу. При неизвестной длительности — подвижная
  шкала без выдуманного процента. В фоне другого приложения индикатор скрыт.
— Окна Audio/MIDI, Aggregate, Project Pool, выбора плагинов и штатных эффектов
  используют цвета DAW. Исправлено закрытие и возврат фокуса.
— При запуске плавно появляется чёрно-белый портрет Дракулы — Бела Лугоши.
— Исправлена ошибка GetWindowSubclass в новых сборках интерфейса.

ОГРАНИЧЕНИЯ АЛЬФЫ
В комплекте CPU-версия PyTorch: NVIDIA сама по себе не включает ускорение CUDA.
Arranger не переносит существующую автоматизацию на новые позиции; он сообщает
об этом в предпросмотре. Внешний MIDI и замороженные дорожки пропускаются.
Загрузка стороннего VST может временно задерживать анимацию индикатора:
плагин не всегда предоставляет сведения о ходе загрузки.

ДОПОЛНИТЕЛЬНО В 0.4.8
- VST2 x64 вместе с VST3; известные папки плагинов других DAW находятся автоматически.
- Controllers: MCU, KeyLab Essential mk3, полноразмерный Launchkey MK3, общий MIDI Learn.
  Akai/Native Instruments: MIDI Learn; NKS и поддержка всех моделей не заявляются.
- SESSION > Import project / FLP / ALS…: начальный импорт нот и аранжировки с отчётом.
  Инструменты, плагины, автоматизация и warp требуют ручной проверки и восстановления.
  Импорт использует Python из компонента Blood Stems: оставьте его выбранным при установке.
- SETTINGS > Animation > Hover glow: отключаемая подсветка наведения; CINEMA усиливает свечение.
  Общий режим OFF также отключает подсветку. Сторонние редакторы плагинов не изменяются.
